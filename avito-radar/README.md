# Avito Radar

Настольное приложение для Windows (Electron), которое **само ищет новые объявления на Авито**
по вашим фильтрам: город и район, цена, ключевые слова, категория. Как только появляется
что-то новое — приходит уведомление на рабочий стол, звук и (по желанию) сообщение в Telegram.

![иконка](assets/icon.png)

## Что умеет

- **Поиск по фильтрам**: запрос, город, цена «от/до», район, категория, обязательные и
  запрещённые слова, скрытие рекламных объявлений.
- **Слежение за новыми**: приложение запоминает всё, что уже видело, и подсвечивает только
  свежие объявления. При повторных проверках видно и **снижение цены**.
- **Расписание**: автопроверка каждые N секунд (по умолчанию 90) со случайным разбросом,
  у каждого поиска можно задать свою частоту.
- **Несколько поисков сразу** — вкладки-профили в левой панели со счётчиками новых.
- **Уведомления**: системные (Windows), звук, Telegram-бот.
- **Работа в трее**: закрыли окно — приложение продолжает следить.
- **Экспорт в CSV** (открывается в Excel) и быстрые ссылки на объявления.
- **Демо-режим** — проверка интерфейса без обращений к Авито.

## Быстрый старт

1. Установите [Node.js LTS](https://nodejs.org/) (нужен только для запуска из исходников).
2. Дважды щёлкните **`START.bat`** — он поставит зависимости и запустит приложение.
   Либо вручную:

   ```bash
   npm install
   npm start
   ```

3. В приложении нажмите **«Новый поиск»** и заполните фильтры.

## Как правильно настроить поиск

Есть два способа, оба работают одновременно.

### 1. Простой: «что ищем» + город + цена

Заполните «Что ищем», «Город» (можно по-русски — приложение транслитерирует),
«Цена от/до». Для мобильного API этого достаточно.

### 2. Точный: ссылка на поиск Авито (рекомендуется)

У Авито сотни фильтров, и **район** удобнее всего выбрать на самом сайте:

1. В форме поиска нажмите **«Открыть Авито»** — откроется страница с вашими фильтрами.
2. На сайте добавьте район, категорию, состояние товара, сортировку «по дате».
3. Скопируйте адрес получившейся страницы и вставьте его в поле **«Ссылка на поиск Авито»**.
4. Сохраните. Приложение будет опрашивать именно эту страницу — со всеми фильтрами,
   которые вы выбрали, включая районы.

Пример ссылки:

```
https://www.avito.ru/kazan/telefony/iphone-ASgBAgICAUSSA8gQ?pmin=30000&pmax=90000&d=1&s=104
```

## Источники данных

| Режим | Что делает | Плюсы | Минусы |
|---|---|---|---|
| **Авто** (по умолчанию) | сначала мобильное API, при ошибке — страница сайта | максимальная живучесть | иногда переключается между источниками |
| **Сайт** | обычная страница поиска avito.ru | все фильтры, включая районы | чаще упирается в антибот (403) |
| **Мобильное API** | неофициальный JSON `m.avito.ru` | быстро, компактно | недокументировано, часть фильтров недоступна |
| **Демо** | генерирует объявления локально | безопасно, без сети | это не настоящие объявления |

Публичного API поиска у Авито нет, поэтому используются те же страницы и запросы, что и в
браузере/мобильном приложении. Ничего не взламывается и не обходится: приложение просто
читает публичные страницы, как обычный посетитель.

**Важно про антибот.** Если Авито отвечает 403/429 или показывает капчу:

- увеличьте интервал проверки (90–180 с);
- уменьшите количество страниц;
- подождите 10–15 минут;
- переключитесь на другой источник в настройках поиска.

## Уведомления в Telegram

1. В Telegram напишите **@BotFather** → `/newbot` → получите токен вида `123456:AA...`.
2. Напишите своему боту любое сообщение (иначе он не сможет вам писать).
3. Узнайте свой **chat_id** у **@userinfobot**.
4. В приложении: ⚙ → «Telegram» → включите, вставьте токен и chat_id → «Проверить подключение».

## Сборка EXE для Windows

```bash
npm install
npm run build:win
```

Готовые файлы появятся в `dist/`:

- `Avito-Radar-1.0.0-x64.exe` — установщик (ярлык на рабочем столе, выбор папки);
- `Avito-Radar-1.0.0-x64-portable.exe` — portable-версия без установки.

Сборку нужно делать на Windows (или в Windows-виртуальной машине). Также есть
`Собрать EXE.bat` — делает то же самое двойным щелчком.

## Где хранятся данные

`%APPDATA%\avito-radar\`

- `config.json` — настройки и все поиски (можно скопировать на другой компьютер);
- `data/<id>.json` — история просмотренного по каждому поиску.

Кнопка «Открыть папку» — в настройках. Удаление поиска удаляет и его историю;
«Сбросить историю» заставляет считать все текущие объявления новыми.

```

  preload.js         безопасный мост в интерфейс

  csv.js             экспорт
  sources/

```

## Ограничения и честные предупреждения

- Авито меняет вёрстку и защиту. Если парсинг перестал работать — обновите приложение
  или переключитесь на другой источник; структура JSON мобильного API тоже может измениться.
- Приложение не входит в аккаунт Авито, не пишет продавцам и не обходит капчу.
- Используйте для личных нужд и с разумными интервалами: слишком частые запросы — это
  нагрузка на чужой сервис и риск блокировки вашего IP.
- Названия «Авито», «Avito» принадлежат их правообладателю; проект неофициальный.
